# Отзывы

Система отзывов позволяет пользователям оставлять оценки и комментарии к выполненным заказам.

---

## Модели данных

### Review
- **id** (UUID) - уникальный идентификатор отзыва
- **order** (ForeignKey) - связь с заказом
- **user** (ForeignKey) - пользователь, оставивший отзыв
- **rating** (Integer) - оценка от 1 до 5
- **comment** (Text) - текстовый комментарий
- **created_at** (DateTime) - дата создания отзыва
- **updated_at** (DateTime) - дата последнего обновления

---

## API Endpoints

### Отзывы (`/api/v1/reviews/`)
- `GET /api/v1/reviews/`: Получение списка отзывов с пагинацией
- `POST /api/v1/reviews/`: Создание нового отзыва (только для авторизованных пользователей)
- `GET /api/v1/reviews/{id}/`: Получение деталей отзыва
- `PUT/PATCH /api/v1/reviews/{id}/`: Обновление отзыва (только автор)
- `DELETE /api/v1/reviews/{id}/`: Удаление отзыва (только автор)

### Параметры запросов
- `rating` - фильтрация по оценке (1-5)
- `user` - фильтрация по пользователю
- `order` - фильтрация по заказу
- `ordering` - сортировка (created_at, rating)

---

## Бизнес-логика

### Создание отзыва
1. Пользователь может оставить отзыв только к выполненному заказу
2. Один пользователь может оставить только один отзыв к одному заказу
3. Оценка должна быть в диапазоне от 1 до 5
4. Комментарий необязателен, но рекомендуется

### Обновление отзыва
1. Только автор может редактировать свой отзыв
2. Изменения логируются в `updated_at`

### Удаление отзыва
1. Только автор может удалить свой отзыв
2. При удалении заказа отзыв также удаляется (CASCADE)

## Фронтенд компоненты

### ReviewsCarousel
- Отображение отзывов в виде карусели на главной странице
- Показывает последние отзывы с высокими оценками
- Автоматическая прокрутка

### Отзывы в профиле
- Список отзывов пользователя
- Возможность редактирования и удаления
- Фильтрация по оценкам

### Форма создания отзыва
- Выбор оценки (звезды 1-5)
- Текстовое поле для комментария
- Валидация на клиенте
- Отправка через React Query

---

## Интеграция

### С заказами
- Отзывы связаны с заказами через ForeignKey
- При просмотре заказа показываются связанные отзывы
- Средняя оценка филиала рассчитывается на основе отзывов

### С пользователями
- В профиле пользователя отображаются его отзывы
- Статистика по количеству и среднему рейтингу

### С филиалами
- Средняя оценка филиала на основе отзывов к заказам
- Отображение в списке филиалов
